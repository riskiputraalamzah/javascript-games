# Koleksi Game JavaScript

Repositori ini berisi kumpulan beberapa game sederhana yang dibuat menggunakan JavaScript. Setiap game berada di dalam branch-nya masing-masing.

## Struktur Repositori

Penting untuk diketahui bahwa setiap game dalam koleksi ini disimpan di branch yang terpisah. Branch `master` hanya berisi file README ini. Untuk mengakses kode game tertentu, Anda harus melakukan clone dari branch yang sesuai.

## Cara Mengunduh Game

Untuk menghemat ruang dan waktu, sangat disarankan untuk hanya meng-clone branch spesifik dari game yang ingin Anda lihat, bukan seluruh repositori.

Gunakan perintah `git clone` dengan flag `-b <nama-branch> --single-branch`.

Berikut adalah daftar game dan perintah untuk mengunduhnya:

### 1. Hexaria

```bash
git clone -b hexaria --single-branch https://github.com/riskiputraalamzah/javascript-games
```

### 2. Shoooter

```bash
git clone -b shoooter --single-branch https://github.com/riskiputraalamzah/javascript-games
```

### 3. Slither.io

```bash
git clone -b slither_io --single-branch https://github.com/riskiputraalamzah/javascript-games
```

### 4. Pacman

```bash
git clone -b pacman --single-branch https://github.com/riskiputraalamzah/javascript-games
```

### 5. Shapez

```bash
git clone -b shapez --single-branch https://github.com/riskiputraalamzah/javascript-games
```

## Menjalankan Game

Setelah proses clone selesai, masuk ke direktori game tersebut dan buka file `index.html` di browser Anda untuk memulai permainan.
